# AI Usage Log

## Development approach
An AI assistant helped with starter code, debugging instructions, and documentation.

## Five useful prompts
1. Design a support knowledge API with article citations.
2. Build a sitemap collector using HTTPX and BeautifulSoup.
3. Create an inbox drafting endpoint with human approval.
4. Structure meeting notes into requirements without inventing estimates.
5. Design tests for retrieval, escalation, validation, and failures.

## Rejected or limited suggestion
Retrieved text could be mistaken for an AI-generated answer. The implementation therefore identifies itself as keyword retrieval with template-based drafting.

## Human oversight
The developer must review and test all generated code. Customer emails are not automatically sent, and proposals require human approval.

## Limitations
No Claude API key was configured. No model comparison or API cost measurement was performed. Only a small sample of support articles was collected. Evaluation cases are planned tests, not verified results.
